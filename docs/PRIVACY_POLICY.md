# Privacy Policy — Loan The Meme

**Effective date:** November 21, 2026
**Developer:** Nguyen Tien Dung ("we", "us")
**Contact:** [your-email@example.com]

## Summary
Loan The Meme is an **offline, single-device game**. We do **not** collect, store, transmit, sell, or share any personal data. There are no accounts, no analytics, no advertising SDKs, and no server owned by us.

## Data we collect
**None.** The game runs entirely on your device.

## Local storage
Game progress (unlocked levels, settings) is saved **only on your device** using local browser/app storage. Deleting the app (or clearing its data) permanently removes it. We cannot access it.

## Peer-to-Peer (P2P) mode
The optional 2-player mode creates a **direct device-to-device connection** (WebRTC) between you and a friend:
- You and your friend exchange a connection code manually (copy/paste). The code contains temporary network information needed to establish the direct link.
- Game data flows **directly between the two devices** and is never routed through, stored on, or visible to any server of ours.
- A public STUN server (e.g. Google STUN) may be contacted once to discover your network address, which is standard for WebRTC connections. No game or personal data is sent to it.

## Children's privacy
The game contains no chat with strangers, no purchases, no ads, and collects no data, and is suitable for general audiences. We do not knowingly collect any information from anyone, including children.

## Permissions
The app requests **no special permissions** (no location, camera, microphone, or contacts). Network access is used only for the optional P2P mode.

## Changes
If a future version ever changes these practices (e.g., adds online services), this policy will be updated and the in-store listing will reflect it before release.
